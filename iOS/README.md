# STAGE CONNECT para iPad

Abre `STAGE CONNECT.xcodeproj` en Xcode (16+), elige un **iPad** y pulsa Run.

- Bundle: `com.entikrecords.stageconnect.ipad`
- Misma clave: `entikmedia` (mes) / `laif` (vitalicia)
- Monitor de decks Denon + Pioneer en la red local

Requiere Xcode completo (no solo Command Line Tools) y un iPad o simulador.
